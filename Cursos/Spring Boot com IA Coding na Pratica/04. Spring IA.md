O Spring Ai se trata de outro projeto do Spring usando para trabalhar com Inteligência Artificial. Ele permite que os desenvolvedores trabalhem de uma forma muito mais dinâmica com diversos provedores de IA, pois ele possui uma estrutura que permite utilizar os LLMs mais utilizados do mercado alterando apenas as configurações de de conexão sem precisar mexer na estrutura da aplicação.

Ademais ele permite trabalhar com Embeddings que são os textos transformados em vetores para trabalhar com bases vetoriais e realizar buscas semânticas na base dados.
