**Conteúdo:** Acompanhe uma cena na qual uma pessoa apresenta toda a família para uma visita, prestando atenção em como adicionar vários nomes de uma vez.
**Após o fim desta aula, você vai conseguir:**
1) Entender conversas simples sobre família 
2) Identificar os parentes falados em um diálogo real 
3) Reconhecer quando duas pessoas são apresentadas juntas
**Especificações:** Comprenhension - 03 Atividades
**Professor(a):** David Medeiros

### Vocabulário
| **FRASE**                  | **TRADUÇÃO**                  |
| -------------------------- | ----------------------------- |
| This is my mom             | _Esta é a minha mãe._         |
| This is my dad             | _Este é o meu pai._           |
| This is my uncle           | _Este é o meu tio._           |
| This is my aunt            | _Esta é a minha tia._         |
| This is the Prime Minister | _Este é o Primeiro-Ministro._ |

### Compreenção
1. "mom" e "dad" são formas de se referir a "mother" e "father" respectivamente.
