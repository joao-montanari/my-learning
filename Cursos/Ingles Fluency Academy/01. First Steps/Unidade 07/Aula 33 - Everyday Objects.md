**Conteúdo:** Aprenda as palavras essenciais para nomear os itens pessoais que carregamos para cima e para baixo, como celular, chaves e carteira.
**Após o fim desta aula, você vai conseguir:**
1) Identificar objetos essenciais do dia a dia
2) Nomear os seus pertences pessoais em inglês de forma simples 
3) Perguntar e responder rapidamente o que é um determinado objeto
**Especificações:** Vocabulary - 03 Atividades
**Professor(a):** Tiago Rocha

### Vocabulário
| **FRASE**       | **TRADUÇÃO**       |
| --------------- | ------------------ |
| What´s this?    | _O que é isso?_    |
| It´s a bag      | _É uma bolsa._     |
| It´s a phone    | _É um telefone._   |
| It´s a key      | _É uma chave._     |
| It´s a wallet   | _É uma carteira._  |
| It´s a computer | _É um computador._ |
| It´s a charger  | _É um carregador._ |
| It´s a bottle   | _É uma garrafa._   |
| It´s a jacket   | _É uma jaqueta._   |

### Exercícios:
**Questão 01:** Você está organizando seus pertences e vê uma bolsa. Como você o identifica em inglês?
- **A)** It´s a wallet
- **B)** It´s a bag
- **C)** It´s a jacket
- **D)** It´s a bottle

**Questão 02:** Você está segurando um computador e alguém te pergunta “What’s this?”. Qual a melhor resposta?
- **A)** It´s a computer
- **B)** It´s a key
- **C)** It´s a charger
- **D)** It´s a bottle

**Questão 03:** Quando está frio, é importante vestir ou levar este item na bolsa. Qual a alternativa correta de acordo com essa descrição?
- **A)** It´s a key
- **B)** It´s a bag
- **C)** It´s a charger
- **D)** It´s a jacket
