O Spring se trata de um ecossistema completo e robusto que pode ser utilizado para desenvolver uma aplicação web simples ou até uma arquitetura distribuída de micro serviços completa.
É possível utilizar diversos do seus sub projetos, tais como:

### Alguns dos principais projetos

| Sub projeto             | Descrição                  |
| ----------------------- | -------------------------- |
| Spring Boot             | apps prontas; p/ produção  |
| Spring Framework        | AOP; DI; MVC               |
| Spring Data             | JPA; Mongo; Redis          |
| Spring Security         | Autenticação; autorização  |
| Spring Cloud            | Config; gateway; discovery |
| Spring AI               | LLMs; RAG; embeddings      |
| Spring Betch            | Processamento em lote      |
| Spring Integration      | Integração de sistemas     |
| Spring Web              | MVC; Webflux               |
| Spring Session          | Sessões distribuidas       |
| Spring HATEOAS          | hipermídia REST            |

| Spring AMQP             | RabbitMQ                   |
| Spring Web Services     | SOAP contract-first        |
| Spring Web Flow         | Fluxos de navegação        |

### Arquitetura do Spring Framework
Quando se trata do ecossistema Spring existe um projeto que é a base de tudo, contendo todas as classes principais. Esse é o Spring Framework.
O Spring Framework é formado por alguns módulos, entre eles se encontram: Web (para trabalhar com aplicações em websites), Data Access/Integration (para acesso a dados, integração e transações)
Veja o ecossistema em Canva: ![[Arquitetura Spring Framework.canvas]]
O que se destaca dentro do Spring Framework é o módulo **Core Container**. Dentro dele é que estão as principais implementações para Beans, Core, Context, SpEL e etc. Dentro dele é onde está a implementação da injeção de controle com a injeção de dependências que torna o Spring tão poderoso, passando para ele a gestão e o gerenciamento de todas as classes de baixo nível para que o desenvolvedor possa focar apenas nas classes de alto nível da aplicação.
