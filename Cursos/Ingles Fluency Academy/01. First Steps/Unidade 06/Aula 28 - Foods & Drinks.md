**Após o fim desta aula, você vai conseguir:**
1) Reconhecer e nomear comidas e bebidas essenciais em inglês
2) Usar “This” e “That” para apontar itens que estão perto ou longe de você

### Vocabulário
| FRASE              | TRADUÇÃO               |
| ------------------ | ---------------------- |
| This is coffee     | _Isso é café._         |
| This is water      | _Isso é água._         |
| This is a sandwich | _Isso é um sanduíche._ |
| That is a pizza    | _Aquilo é uma pizza._  |
| That pizza         | _Aquela pizza_         |
| That is an agg     | _Aquilo é um ovo._     |
| That is fruit      | _Aquilo é fruta._      |

### Vocabulário
1. O "This" é utilizado para se referir a coisas que estão perto de você enquanto o "That" é para coisas que estão longe.

### Exercícios:
**Questão 01:** Você está em uma cafeteria e vê um café perto de você. Olhe a imagem e escolha a frase correta em inglês:
- **A)** This is coffee
- **B)** That is coffee
- **C)** This is water
- **D)** That is pizza

**Questão 02:** Durante um almoço, o garçom traz um copo de água e o deixa bem na sua frente. Como você pode falar sobre isso em inglês?
- **A)** This is coffee
- **B)** This is water
- **C)** This is pizza
- **D)** This is egg

**Questão 03:** Você está em um restaurante e aponta para a mesa vizinha, onde há uma pizza que você quer pedir. Qual é a forma certa de indicar isso para o garçom?
- **A)** This pizza
- **B)** That pizza
- **C)** This egg
- **D)** That coffee
