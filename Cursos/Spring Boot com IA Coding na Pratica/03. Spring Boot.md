O Spring Boot se trata de um dos projetos que fazem parte do ecossistema do Spring e com ele é possível iniciar uma aplicação de uma forma muito rápida e simples. Esse é um ponto positivo principalmente quando utilizamos de uma arquitetura de micro serviços pois o Spring Boot permite iniciarmos o projeto de uma forma muito mais produtiva.

Antes da existência do Spring Boot era necessário configurar o Spring Framework do zero, ou seja inserir diversas configurações de web, XML, servidor externo e etc.

Agora com o Spring Boot ficou muito mais simples pois ele já trás consigo o Spring Framework, Servlet Container embutido, Auto-configuration e Starters
