Beans são objetos gerenciados pelo Core Container do Spring Framework. Assim, podemos dizer que na realidade os Beans são as classes Java que criamos dentro da aplicação e sinalizamos que o próprio Spring vai gerenciar e controlar. O Sping vai criar, injetar e controlar o ciclo de vida do Beans.

Ao criar um Beans podemos utilizar algumas anotações do próprio Spring para demonstrar qual tipo de classe Bean ele vai ter que gerenciar. Assim fica mais explicito qual vai ser a relação do Bean com a aplicação.

A anotação mais comum é a `@Component` sendo o estereótipo genérico. Porém, existem outras anotações que permitem especificar ainda mais o Bean que está sendo criado, veja abaixo:

| Anotação      | Especificação        | Descrição                                                                                                                                                                                  |
| ------------- | -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `@Component`  | Estereótipo genérico | É a anotação genérica básica. Marca uma classe Java comum como um Bean gerenciado pelo Spring. As outras anotações abaixo são apenas especializações do `@Component`.                      |
| `@Repository` | Camada de dados      | Usada para classes de acesso a dados (como DAOs - Data Access Objects). Além de criar o Bean, ela também converte exceções específicas de banco de dados em exceções genéricas do Spring.  |
| `@Service`    | Camada de negócio    | Usada para marcar classes que contêm a lógica de negócios da sua aplicação. Não muda o comportamento técnico em relação ao `@Component`, mas deixa a semântica do código muito mais clara. |
| `@Controller` | Camada web           | Marca a classe como um controlador web tradicional (geralmente retornando Views/HTML).                                                                                                     |
